Kaizen Restaurante - Proyecto producción

Archivos:
- index.html
- styles.css
- script.js

Instalación:
1. Sube los 3 archivos a la raíz de tu hosting.
2. Asegúrate de que index.html cargue styles.css y script.js con rutas relativas.
3. Reemplaza las imágenes de Unsplash por tus fotos reales si ya las tienes.
4. Si quieres cambiar el mapa, actualiza el iframe en index.html.
